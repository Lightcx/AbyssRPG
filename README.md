# 暗影深渊 · Shadow Abyss

**当前版本 v0.3.0**

## 怎么玩

点击 https://lightcx.github.io/AbyssRPG/ 即玩。

### 操作

两套**完全分离**的模式，在**设置（`O`）**里切换，各自维护独立按键。**新玩家默认是键盘（WASD）模式**。

**鼠标模式**

| 操作 | 说明 |
| --- | --- |
| 左键 | 只移动：点击地面移动，按住持续跟随光标 |
| 右键 | 普攻：点击向光标方向攻击 |
| `1` `2` `3` `4` | 释放四个主动技能 |

**WASD 模式（默认）**

| 操作 | 说明 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| 左键 | 普攻：点击向光标方向攻击 |
| 右键 | 技能 1 |
| `1` `2` `3` | 技能 2 / 3 / 4 |

**通用**

| 操作 | 说明 |
| --- | --- |
| `Shift` + 左键 | 朝该方向强制普攻 |
| `Ctrl` + 左键 | 强制移动到该点 |
| `空格` | 翻滚闪避：消耗 1 格**闪避充能**，约 0.4 秒无敌、可穿怪；基础 **2 秒回满一格** |
| `Q` / `E` | 生命 / 法力药水 |
| `F` | 拾取附近物品；与 NPC 互动 |
| `I` `C` `V` `H` | 背包 / 角色 / 商人 / 帮助 |
| `G` `K` `B` `O` | 做装工坊 / 仓库 / 城镇建设 / 设置 |
| `T` | 城镇 ↔ 深渊（深渊中回城需脱战） |
| `M` | 大地图 |
| `Esc` | 暂停菜单 |
| `Alt` | 显示地面全部物品名 |
| `Shift` + 点物品 | 快速装备 / 快速出售 |

### 设置（`O`）

* 入口：底部工具栏「设置」、快捷键 `O`，或 `Esc` 暂停菜单 → 游戏设置。
* **操作模式**：切换 鼠标/WASD 操作模式。
* **按键重绑定**：自定义按键绑定。`Delete` 清除绑定、`Esc` 放弃。
* **音效**：开 / 关。
* **音量**：**背景音乐**与**音效**各一条滑条（0~100，拖动实时生效）。
* **按键绑定**：点「**自定义按键**」按钮弹出改键小窗（默认不展开），在里面点按键按钮后按下新键即可；`Delete` 清除、`Esc` 放弃。
* **背景音乐**：深渊一首、营地与训练场一首，随区域自动切换；素材放在 `assets/`。
* **界面显示**：头顶血条、头顶蓝条、脚下闪避条（默认全开）。

### 角色面板（`C`）

悬停技能 / 天赋条目即浮出说明：

* **当前状态**：等级（含装备加成）、基础伤害、武器倍率、法力消耗、实际冷却（含冷却缩减）、减速 / 眩晕 / 穿透 / 持续时间 / 半径等特效。
* **加点收益**：
* **被动天赋**

### 技能强化分支（点击技能打开）

**点技能条目**打开**强化窗口**。

* **档位**：每5级解锁强化分支。25级解锁三条强力分支。
* **同档互斥**：同档位分支只能选一条，换分支去找**深渊向导**洗点。
* **解锁与生效都看实际技能等级**：通过技能等级加成超过档位，可正常分配分支并生效；掉回需求以下则**保留选择、暂时失效**。
* **25 级之后**：技能超过25级后，数值仍涨但**不再有新分支**，且每级收益递减。
* **「替换基础闪避」**：三职业位移技能的 25 级分支其中之一。选中后**闪避键改为释放该技能**

### 洗点（深渊向导 · 塞拉）

塞拉（城镇南侧）**负责洗点**，费用为金币 + 深渊残晶：

| 对象 | 费用挂钩 | 效果 |
| --- | --- | --- |
| 属性点 | 只有人物等级 | 退还全部已分配属性点（力 / 敏 / 智 / 体一起重置） |
| 被动天赋 | 等级 + 该被动已投入点数 | 退还该被动全部点数 |
| 技能 | 等级 + 该技能已投入点数 | 退还全部技能点，并**清空其强化分支** |

```
属性：金币 = 180 × 等级 × (1 + 等级/50)　　残晶 = 3 + ⌊等级/6⌋
被动：金币 = 160 × 等级 × (1 + 点数/6)　　 残晶 = max(1, 2 × 点数 × (1 + 等级/40))
技能：金币 = 140 × 等级 × (1 + 点数/8)　　 残晶 = max(1, 1.2 × 点数 × (1 + 等级/40))
```

### 核心循环

1. **余烬营地** 整理装备、做装、升级建筑。
2. **深渊之门** 选层数 + 难度进入地牢。
3. 清掉 **80% 怪物** 打开下层的传送门，按 `F` 进下一层；每 **5 层**一位**深渊领主（BOSS）**。
4. 装备等级 = 当前怪物等级，层数越深掉落越强。
5. 背包装不下就回入口的**回城传送门**按 `F`（或脱战后按 `T`）把金币、装备、材料带回城镇。
6. 死亡损失 10% 金币，3 秒后在本层入口复活。
7. 每 20 秒与每次换层自动存档。

### 难度等级

| 分级 | 决定什么 |
| --- | --- |
| **深渊层数** | 怪物等级（约 层数 × 1.2），即本层怪物强度与掉落等级 |
| **难度等级** | 在层数之上叠加怪物生命 / 伤害 / 掉落率 / 掉落品质（只额外加 0-5 级怪物等级） |

难度 6 档：普通 → 专家 → 噩梦 → 地狱 → 炼狱 → 湮灭。解锁条件是在**当前难度**击败「下一个 5 的倍数层」的领主。

### 装备过滤器

背包面板右下角「**过滤器**」打开，用于让背包 / 仓库 / 商店装备与**地面掉落**按规则**隐藏或高亮**：

* 最多 **20 条规则**，**靠前的优先生效**。
* 一条规则可含**多条细则**，必须**同时满足**。细则类型：物品等级、稀有度、部位、装备类型、包含词缀、需求等级、需求属性、词缀条数、词缀品质、孔位数、是否双手、是否穿得上、评分。
* 动作：**显示 / 高亮显示（绿框 + ◆）/ 隐藏**。**地面上的隐藏掉落默认不显示也捡不到**，只有长按显示键并**用鼠标点它**才能捡起。
* **导入 / 导出**：导出弹窗里是 JSON，点「复制」备份或转发；粘进导入窗口点「导入」即可覆盖。
* **长按显示全部装备**：默认长按 **X**（设置 → 按键绑定里可改）。按住期间**地上**被隐藏的装备照常显示，松开即恢复；此时**用鼠标点**可以捡起，但**按 `F`（或走近自动吸取）永远只捡没被隐藏的**。

### 存档位

* 开局 **20 个存档位**，可同时培养不同职业；存档列表一行一个存档（横幅式），空位只显示一条 **+ 新存档**，一屏放不下时滚动查看。
* 每位独立保存角色、装备、背包、仓库、建筑等级、残晶、层数与所在地；横幅标题是「**序号 - 职业名**」（例：`1 - 野蛮人`、`15 - 法师`），后面跟着职业图标 / 等级 / 游戏时间 / **到达过的最深层数** / 当前难度 / 金币与残晶 / 最后保存时间，右侧 **✕** 可单独删除。
* **共享仓库例外**：通货石与宝石放在跨存档仓库里（每种上限 9999），所有角色共用。

### 做装玩法（通货石）

击杀精英与 BOSS 掉落**通货石**（商人也有售），在【秘法工坊】（`G`）对装备使用：

* **左边**：**物品栏**与**装备栏**，点击选中装备。
* **右边**：**工作台** —— 选中装备在正中，四周**环绕通货石**。
* **操作**：左键点通货拿起，再点中央装备进行改造；右键 / `Esc` 放下。无存货或对当前装备不可用时节点变暗。
* **数量统计**，节点显示库存总数、悬浮列出各处数量；**消耗顺序：背包 → 共享仓库 → 个人仓库**。

悬浮中央装备可看完整属性、词缀档位与数值范围；每次改造后左下角记录给出改动明细与评分变化。

| 通货石 | 效果 |
| --- | --- |
| 净化石 | 抹去魔法 / 稀有装备的全部词缀，还原为普通装备 |
| 增幅石 | 为词缀未满的装备加 1 条随机词缀 |
| 晋升石 | 普通 → 魔法，并加随机词缀 |
| 炼化石 | 魔法 → 稀有，并加随机词缀 |
| 点金石 | 提升基底与词缀数值 |
| 裂解石 | 随机移除一条词缀 |
| 混沌石 | 重掷全部词缀，**不改稀有度与孔位** |
| 传说石 | 为稀有装备注入随机暗金特效，保留自身词缀；重复使用会**刷新暗金特效** |
| 钻孔石 | 增加一个孔位（上限见部位表） |

### 装备与掉落

* 稀有度：**普通 → 魔法 → 稀有 → 暗金 / 传奇**（颜色与地面光柱区分）。
* 11 类武器 × 8 个等级段（匕首 / 剑 / 斧 / 锤 / 巨剑 / 巨斧 / 弓 / 弩 / 法杖 / 魔杖 / 权杖），7 类护甲 + 盾牌 / 法球 / 箭袋 + 戒指项链。
* 43 条词缀（**20 前缀 + 23 后缀**），按物品等级分 8 档并**档间插值**，同组互斥。
* **前后缀分工**：
  * **前缀**：四维属性、武器伤害与附加元素伤害、元素伤害 %、暴击率 / 暴击伤害、护甲 / 护甲 %、技能等级 / 全技能等级。
  * **后缀**：生命 / 法力上限、抗性（全抗 + 四系单抗）、攻速（已并入施法速度）、移速、生命 / 法力偷取、每秒生命 / 法力回复、受到伤害降低、掉落率（魔法装备 / 金币）、经验获取、冷却缩减、范围伤害、闪避、拾取范围、**闪避充能次数**、**闪避恢复时间**。
* **孔位标识**：图标下方用**菱形**表示，一孔一颗，无孔不显示。
* **宝石镶嵌**：点背包里的宝石「拿起」（图标跟随光标），再点有孔装备镶嵌；右键 / `Esc` 放弃。可在珠宝匠处取下。
* **档位方向与 PoE 一致：T1 最强、T8 最弱**（由物品等级决定，8 档分界 ilvl 1/8/17/27/39/52/66/80）。配色 `T1 红 · T2 粉 · T3-T4 青 · T5-T6 绿 · T7-T8 灰`。
* **整理规则**：`稀有度优先 → 同稀有度内可提升的靠前 → 物品等级`。
* **孔位上限按部位**：主手 / 副手 / 头 / 靴 / 手 / 腰 **2 孔**，胸甲 **3 孔**，戒指 **1 孔**，项链 **2 孔**，**双手武器 4 孔**（= 主 2 + 副 2）；低等级开不满，随物品等级放开（每 20 ilvl 多开 1 孔）。6 种宝石 × 5 品质（红 / 绿 / 蓝宝石、紫水晶、黄玉、钻石）。
* **掉落品质随进度递进**（层数 + 难度）：1-10 层白装为主、蓝少、黄罕见、暗金是惊喜；11-25 层蓝为主、白明显变少、词缀不满的黄开始出现；26-40 层蓝黄并重、满词缀黄出现、暗金小概率；41-55 层黄为主、白基本绝迹、暗金稳定；56 层以上多词缀黄与暗金为主。难度每高一档把阶段前推一档并放大高稀有度权重，MF 再乘一次；高阶段黄装不仅更常见，词缀也更易掷满。
* **宝石**，每品质独立图标（`◇ 碎裂 → ◈ 裂开 → ◆ 完整 → ✦ 无瑕 → ★ 完美`），地上掉落随品质变大、增加切面。
* **武器秒伤、护甲坚韧**：
  * **秒伤** = `(物理均值 × 增伤 + 附加元素 × 0.9) × 攻速（含武器自身攻速词缀）`；对比时两窗各带 `▲ / ▼`，空槽不显示差值。
  * **坚韧**：满血能承受的「减伤前」伤害，逐系 `生命 ÷ (1 − 减伤) ÷ (1 − 闪避) ÷ (1 − 受到伤害降低)`（物理用护甲减伤，火 / 冰 / 电 / 毒用对应抗性），**总坚韧 = 五类平均**。角色面板只显示总值，悬停展开五系分项与计算输入（生命上限 / 护甲 / 闪避 / 受到伤害降低）。
