# 暗影深渊 · Shadow Abyss

**当前版本 v0.1.0**　·　变更记录见 [`CHANGELOG.md`](CHANGELOG.md)　·　仓库 <https://github.com/Lightcx/AbyssRPG>

一个用原生 JavaScript + Canvas 写的**类《暗黑破坏神》刷宝 ARPG**，无需任何依赖、无需构建、无需 package.json，双击 `index.html` 即可玩。

**技术栈**：HTML + CSS + 原生 ES5 风格 JavaScript（classic script，无模块打包、无框架、无依赖）、Canvas 2D、WebAudio、localStorage。没有构建步骤，也没有 npm 依赖——`tools/` 里的三个脚本只在需要时用 `node` 直接跑。

## 怎么玩

直接打开 `index.html`（Chrome / Edge / Firefox 均可）。

> 如果浏览器禁止 `file://` 使用 localStorage 导致无法存档，可在目录里跑一个静态服务器：
> `npx serve .` 或 `python -m http.server`，然后访问对应地址。

### 操作

游戏提供两套**完全分离**的操作模式，可在 **设置（`O`）** 中随时切换，两套模式各自维护独立的按键绑定。

**鼠标模式（默认）** —— 适合类暗黑玩法

| 操作 | 说明 |
| --- | --- |
| 鼠标左键 | **只移动**：点地面走过去；按住持续跟随光标走位 —— 角色周围有约 34px 的**鼠标死区**，光标进入死区就停下，移出后立刻恢复移动 |
| 鼠标右键 | **普通攻击**：点中敌人会锁定并持续攻击（远程自动保持距离），点空地则朝该方向连续射击 |
| `1` `2` `3` `4` | 释放四个主动技能 |

**WASD 模式** —— 适合动作 / 双摇杆玩法

| 操作 | 说明 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| 鼠标左键 | **普通攻击**：朝准星方向出手，绝不会自动移动（近战需自己贴近） |
| 鼠标右键 | 技能 1 |
| `1` `2` `3` | 技能 2 / 3 / 4（例：猎魔人 = 穿刺箭 / 毒云 / 影袭） |

**两种模式通用**

| 操作 | 说明 |
| --- | --- |
| `Shift` + 左键 | 朝该方向强制普通攻击（按住持续） |
| `Ctrl` + 左键 | 强制移动到该点 |
| `空格` | 翻滚闪避（约 0.4 秒无敌，可穿过怪物） |
| `Q` / `E` | 喝生命 / 法力药水 |
| `F` | 拾取附近所有物品；**进入下一层传送门**；在城镇中与身边的 NPC 交谈 / 踏上深渊之门 |
| `I` `C` `V` `H` | 背包 / 角色 / 商人 / 帮助 |
| `G` `K` `B` `O` | 做装工坊 / 仓库 / 城镇建设 / 设置 |
| `T` | 城镇 ↔ 深渊（地牢中需脱离战斗；入口处的回城传送门按 `F` 也能回城） |
| `M` | 切换大地图 |
| `Esc` | 暂停菜单（继续 / 保存 / 返回存档列表 / 删除本存档） |
| `Alt` | 显示地面全部物品名称 |
| `Shift + 点击物品` | 快速装备 / 快速出售 |

### 设置（`O`）

* 入口：底部工具栏「设置」按钮、快捷键 `O`，或 **`Esc` 暂停菜单 → 游戏设置**（从暂停进入时游戏保持暂停，关掉设置会回到暂停菜单）。
* **操作模式**：鼠标模式 / WASD 模式，一键切换，技能栏上的按键提示会同步变化。
* **按键重绑定**：23 个动作（攻击、4 个技能、移动、翻滚、药水、拾取、各面板……）都可以改键。
  点击动作右侧的按键按钮 → 按下新按键即可；`Delete` 清除绑定，`Esc` 放弃修改。
  同一模式下同一个按键只会保留一个动作（冲突时旧的自动解绑）。若攻击等核心键未绑定，面板会给出警告。
* **音效**：开 / 关。
* 设置保存在 `localStorage`（独立于存档位，所有角色共用）。

### 角色面板（`C`）

把鼠标停在技能或天赋条目上，会浮出完整说明：

* **当前状态**：等级（含装备加成，如「已投入 3 点　装备 +2」）、基础伤害、武器伤害倍率、法力消耗、实际冷却（已计入冷却缩减）、减速/眩晕/穿透/持续时间/作用半径等特效。
* **加点收益**：`基础伤害 67 → 74（+6，+9.4%）`、`伤害倍率 464% → 507%`、每点成长值，以及剩余技能点；未达等级要求时提示所需等级，满级时显示「已满级」。
* **被动天赋**同样显示「当前效果 → 下一级效果」以及本次提升的具体属性。

技能栏（屏幕底部）上的图标悬浮时也会显示同一套说明。

### 技能强化分支（点击技能打开）

技能不再在角色面板里直接加点：**点击技能条目**会打开该技能的**强化窗口**，加点与分支选择都在窗口里完成。

```
                                  ○ 5级分支-a        ○ 10级分支-a  ...
                     ╭────────┐
   技能图标  ─────────┤ 5   10   15   20   25 ├───────╮   ○ 25级强力分支-a
                     ╰────────╯                       ├── ○ 25级强力分支-b
                                  ○ 5级分支-b        ...  ╰── ○ 25级强力分支-c
```

* **档位**：技能达到 **5 / 10 / 15 / 20 级** 时各解锁 **2 个**可选分支，**25 级**时解锁 **3 个**更强力的分支（共 11 个）。
* **同档位互斥**：一个档位只能选一个分支，选完其它分支会锁死；想换分支必须去城镇找**深渊向导**洗点。
* **解锁与生效都看「实际技能等级」**（手动投入 + 装备 / 宝石 / 天赋加成）：
  * 装备把技能顶过档位需求 → **可以正常分配**，效果也正常生效；
  * 脱下装备导致等级掉回需求以下 → **分支选择保留但暂时失效**（节点变红、提示「失效（技能等级不足）」，角色面板也会显示「N 项失效」），重新穿上立刻恢复。
* **25 级之后**：技能等级上限为 25 点，装备加成可以继续往上顶 —— 数值仍然提升，但**不再有新分支**，且每级收益**等比递减**（26 级 = 95%、27 级 = 90.3%、28 级 = 85.7%……），永远不会归零，累计约等于再给 19 个正常等级。
* 分支效果覆盖：技能伤害、**攻击速度**（普通攻击）、法力消耗、冷却、作用范围/扇形角度/位移距离、弹道数量、投射物速度与体积、穿透、持续时间、持续伤害、爆炸范围、增益强度、眩晕/减速/**点燃**/**溅射**、击退、暴击率与暴击伤害、对首领伤害、斩杀（对低血目标加伤）、**生命偷取**、**击杀回法**、元素转化等。
* 同一档位的两个分支强度对齐，只换取向（伤害 / 范围 / 机动 / 特效）；**不会塞「命中回复 N 点生命」这类数值过低的属性**（续航走生命偷取 % 与击杀回蓝）。

### 洗点（深渊向导 · 塞拉）

城镇的**深渊向导 · 塞拉**（南侧）**只负责洗点**（进入深渊请用南边的深渊之门），费用为 **金币 + 深渊残晶**：

| 洗点对象 | 费用挂钩 | 效果 |
| --- | --- | --- |
| **属性点** | **只有人物等级** | 退还全部已分配属性点（力量/敏捷/智力/体力一起重置） |
| **被动天赋** | 人物等级 + **该被动已投入的点数** | 退还该被动的全部点数 |
| **技能** | 人物等级 + **该技能已投入的点数** | 退还该技能全部技能点，并**清空它的强化分支** |

费用公式（`D.respecCost`）：

```
属性：金币 = 180 × 等级 × (1 + 等级/50)　　残晶 = 3 + ⌊等级/6⌋
被动：金币 = 160 × 等级 × (1 + 点数/6)　　 残晶 = max(1, 2 × 点数 × (1 + 等级/40))
技能：金币 = 140 × 等级 × (1 + 点数/8)　　 残晶 = max(1, 1.2 × 点数 × (1 + 等级/40))
```

技能洗点**只看手动投入的点数**：装备/宝石提供的技能等级既不增加费用，也不在退还范围内（洗完后这些加成依然生效）。被动与技能的洗点逐条列出，资源不足时按钮置灰并标红缺口。

**首次引导**：第一次与塞拉交谈（每个存档一次，随存档记录）她会**分 5 段**讲完，用「继续 ▸ / ◂ 上一段」翻页，每段都同时写进左下角日志：

1. **你是谁** —— 她的身份与能提供的帮助，以及「想变强就得深入深渊，旁边那道深渊之门会打开道路」。
2. **怎么变强** —— 积攒战斗经验变强、每五次额外悟出天赋，以及战斗技艺磨练后能使用特殊技巧（并且这些技巧彼此互斥）。
3. **营地里这些人** —— 铁匠布洛克（分解装备 → 深渊残晶）、秘法工匠维恩（残晶与通货石 → 装备）、祭司娜塔（营地建设 → 深渊收益）、仓库管理员米尔（仓库，含宝石与通货石货仓）、流浪商人加兹与珠宝匠凯（金币交易 / 宝石合成与取下）。
4. **深渊里的规矩** —— 越深越强、每五层一位深渊领主、战败后由她复活但需要一部分金币、镶孔与宝石、残晶与通货石是硬通货。
5. **重新分配力量** —— 洗点收费，以及「去旁边那道门吧，活着回来」。

对白全部用营地居民的口吻写，**不出现按键名、面板、点击等跳出世界观的词**（有测试守着这一条）。收起后她会留一句短提示，旁边可以「再说一遍」重新翻看。

### 核心循环

1. 在**余烬营地**（城镇）整理装备、做装、升级建筑。
2. 站上南侧的**深渊之门**按 `F`，在面板里**选层数 + 选难度**后进入地牢。
3. 清掉 **80% 怪物** → 传送门**直接开在角色身边**（不用满地图找），走近后按 `F` 进入下一层；每 **5 层** 出现一个 **深渊领主（BOSS）**。
4. 装备等级 = 当前怪物等级，越深层的掉落越强。
5. 背包装不下时，回到入口的**回城传送门**按 `F`（或脱离战斗后按 `T`）把金币、装备与材料带回城镇。
6. 死亡损失 10% 金币，3 秒后在本层入口复活（进度不丢）。
7. 每 20 秒与每次换层自动存档（localStorage，**3 个独立存档位**）。

### 层数 与 难度等级

两套分级彻底分开，互不干扰：

| | 决定什么 | 怎么提升 |
| --- | --- | --- |
| **深渊层数** | 怪物等级（层数 × 1.2 左右），也就是这一层怪物的基础强度与装备掉落等级 | 一路往下打 |
| **难度等级** | 在层数之上叠加**怪物生命 / 伤害 / 掉落率 / 掉落品质**（只额外加 0-5 级怪物等级） | **击败领主解锁** |

难度共 **6 档**：普通 → 专家 → 噩梦 → 地狱 → 炼狱 → 湮灭。解锁规则是在**当前难度**击败「下一个 5 的倍数层」的深渊领主：

* 普通难度击败第 **5** 层领主 → 解锁**专家**
* 专家难度击败第 **10** 层领主 → 解锁**噩梦**
* 噩梦第 15 层 → **地狱**；地狱第 20 层 → **炼狱**；炼狱第 25 层 → **湮灭**

难度在**深渊之门**面板里切换（只显示已解锁的档位，未解锁的会写清条件），难度与层数一样会随存档保留。

### 当前层缓存

**只缓存你正在打的那一层**：

* 回城买东西、或者刷新页面后再进同一层，**怪物（含剩余血量与死亡状态）、地上的掉落、砸坏的罐子、击杀进度、走过的地方与你的位置**都会原样回来。
* 一旦进入**别的层数**，或者切换了**难度**，旧缓存立即作废，那一层会重新生成。
* 存档时缓存一起写进 localStorage，所以关掉浏览器也不会丢。

### 装备过滤器

背包面板右下角的**「过滤器」**按钮打开。用来让背包 / 仓库 / 商店里的装备按你的规则**隐藏或高亮**：

* 最多 **20 条规则**，**靠前的规则优先生效** —— 装备命中第一条满足的规则就按它处理，后面的不再看。
* 一条规则里可以放**多条细则**，所有细则必须**同时满足**。细则类型：物品等级、稀有度、装备部位、装备类型、包含词缀、名称包含、需求等级 / 力量 / 敏捷 / 智力、词缀条数、词缀品质、孔位数、是否双手、当前是否穿得上、评分。
* 规则动作：**显示 / 高亮显示（绿框 + ◆ 标记）/ 隐藏**（格子变淡并显示 ✕，仍然占格、仍然可点，悬浮能看到是哪条规则隐藏了它）。
* **导入 / 导出**：把规则导出成 JSON 文本就能备份或发给别人，粘贴文本再点「从文本框导入」即可。配置对所有存档通用。
* 面板里还有「临时显示被隐藏的物品」开关，方便检查被藏起来的东西。

### 存档位

* 开局界面提供 **3 个存档位**，可以同时培养不同职业的角色。
* 每个存档位独立保存：角色、装备、背包、仓库、城镇建筑等级、残晶、层数与所在地。
* 存档卡片显示职业、等级、所在地、难度、金币、击杀与游戏时长；可分别删除。
* 旧版单存档会自动迁移到存档位 1。
* **共享仓库例外**：通货石与宝石存在独立的跨存档仓库里（每种上限 9999），删档也不会消失，所有角色共用。

### 城镇「余烬营地」

带回城镇的不只是金币：这里提供完整的**服务链**，全部 NPC 都可以走近后按 `F` 交谈：

| 地点 / NPC | 功能 |
| --- | --- |
| **铁匠铺 · 布洛克** | **分解装备**换取「深渊残晶」；一键分解白装 / 魔法及以下（会自动保留比身上更好的） |
| **秘法工坊 · 维恩** | **做装**：用通货石改造装备（快捷键 `G`） |
| **深渊祭坛 · 娜塔** | **城镇建设**（快捷键 `B`） |

### 做装玩法（通货石）

在地牢中击杀精英怪与 BOSS 会掉落**通货石**（商人也有出售），在城镇【秘法工坊】（快捷键 `G`）对装备使用。

**做装界面**分成左右两块：

* **左边**：**物品栏**（背包里所有可改造的装备，点一下即放上工作台）与**装备栏**（身上的装备也能改造），当前放上工作台的那件会高亮；点格子/装备即切换，右键还能直接「装备」。
* **右边**：**工作台** —— 选中的装备显示在正中央，四周**环绕着全部 9 种通货石**，每个节点显示图标、名称与持有数量，悬浮可见完整说明与当前是否可用。环绕顺序固定为（正上方起顺时针）：**净化石 → 增幅石 → 晋升石 → 炼化石 → 点金石 → 裂解石 → 混沌石 → 传说石 → 钻孔石**（改顺序只改 `js/ui.js` 里的 `UI.BENCH_ORDER`）。
* **操作和宝石镶嵌一致**：**左键点通货 = 拿起**（图标跟随光标，工作台中央会高亮并提示「点击使用 ◈ 晋升石」），**再点中央的装备 = 消耗该通货改造**；右键 / `Esc` 放下。没有存货或对当前装备不可用时节点会变暗。
* **通货数量自动统计「背包 + 个人仓库 + 跨存档共享仓库」**，节点上显示的是总数，悬浮提示会列出各处分别有多少；**消耗顺序为 背包 → 共享仓库 → 个人仓库**。改造失败（例如条件不满足）不会消耗通货。

使用前悬浮中央装备即可看到完整属性、词缀档位与数值范围；每次改造后左下角记录给出改动明细与评分变化。

| 通货石 | 效果 |
| --- | --- |
| **净化石** | 抹去魔法与稀有装备上的所有词缀，将其还原为普通装备 |
| **增幅石** | 为词缀未满的装备增加 1 条随机词缀（蓝装最多 1 前 + 1 后，黄装最多 3 前 + 3 后） |
| **晋升石** | 把普通装备提升为魔法装备，并增加随机词缀 |
| **炼化石** | 把魔法装备提升为稀有装备，并增加随机词缀 |
| **点金石** | 提升装备基底与词缀的数值 |
| **裂解石** | 随机移除装备上的一条词缀 |
| **混沌石** | 重掷装备上的全部词缀。**不改变装备稀有度或孔位** |
| **传说石** | 为稀有装备注入一条随机的暗金特效，保留装备自身词缀；**对已被注入的装备重复使用会刷新其暗金特效**（换一条，不会重复同一条） |
| **钻孔石** | 为装备增加一个孔位（上限见各部位：胸甲 3 孔、双手武器 4 孔，其余多为 2 孔，戒指 1 孔） |

### 装备与掉落

* 稀有度：**普通 → 魔法 → 稀有 → 暗金/传奇**（颜色与地面光柱区分）。
* **深渊残晶也会直接从怪物身上掉落**：普通怪约 5%、精英约 22%、BOSS 约 75% 的几率掉一颗青色晶体，拾取后**直接进残晶池、不占背包**（和金币一样在拾取范围内自动吸取），数量随怪物等级提升。**秘法工坊**每级额外提供 +20% 残晶掉落率。分解装备仍然是最稳定的残晶来源。
* 11 类武器 × 8 个等级段（匕首/剑/斧/锤/巨剑/巨斧/弓/弩/法杖/魔杖/权杖），7 类护甲 + 盾牌/法球/箭袋 + 戒指项链。
* 41 条词缀（**20 前缀 + 21 后缀**），按物品等级分 8 档并做**档间插值**，数值随等级平滑成长；同组词缀互斥。
* **前缀 / 后缀分工明确**：
  * **前缀**：四维属性（力/敏/智/体）、武器伤害与附加元素伤害、元素伤害%、**暴击率**、**暴击伤害**、**护甲 / 护甲%**、**技能等级 / 全技能等级**。
  * **后缀**：**生命上限 / 法力上限**、**抗性**（全抗 + 火/冰/电/毒单抗）、**攻击速度**（已把施法速度并入）、**移动速度**、生命 / **法力偷取**、每秒生命 / **法力回复**、受到伤害降低、**掉落率**（魔法装备 / 金币）、**经验获取**、冷却缩减、范围伤害、闪避、拾取范围。
* **词缀数量上限**：普通 0 条；**魔法（蓝）最多 1 前缀 + 1 后缀**；**稀有（黄）最多 3 前缀 + 3 后缀**（共 6 条）。提示框直接显示 `前缀 2 / 3　后缀 1 / 3`，满格变绿。
* **部位限制**：
  * `护甲 / 护甲% / 生命 / 法力 / 抗性` **只出现在护甲类装备**（头盔 / 胸甲 / 手套 / 靴子 / 腰带 / 副手）。
  * `移动速度` **只出现在靴子与项链**上。
  * **戒指不受任何限制**，可以出现全部前后缀（包括护甲、护甲%、移速等）。
* 掉落生成的黄装通常 3-5 条，第 6 条要靠【增幅石】补满；每个装备部位的前后缀池都保证能填满 3 + 3（最少 12 条）。
* **词缀数值一目了然**：提示框里每条词缀都会显示 `前/后 标识 + 档位徽章 + 该档数值范围 + 数值填充条`（前缀橙色「前」、后缀蓝色「后」，且前缀统一排在后缀前面），满数值会高亮；顶部还会显示「数值品质 %」与「已做装次数」。
* **装备栏布局**：3 列 4 行 —— **头盔居中在第一行**，下面三行是 `手套 | 胸甲 | 项链`、`主手 | 腰带 | 副手`、`戒指1 | 靴子 | 戒指2`；格子为竖向方块（图标在上、名称在下、孔位菱形在底部），空槽位虚线显示「部位 · 空」。做装工坊左侧的装备栏用同一套排布。
* **悬停未穿戴的装备**（背包 / 仓库 / 商人）时，提示框会变成**左右并列的两个窗口**（中间一条竖线分隔）：左边「已穿戴装备」，右边「新装备」，两边的完整属性（含词缀档位）并排显示，底部给出评分结论。戒指会同时列出戒指 I 与戒指 II，共三个窗口。
* **孔位标识**：装备图标下方用**菱形**表示孔位 —— 一个孔一颗菱形，无孔则不显示；已镶嵌的菱形会显示对应宝石的颜色（最多 4 孔，一排显示）。
* **宝石镶嵌**：点击背包里的宝石会把它**「拿起」**（图标跟随光标），再点击有孔位的装备才镶嵌；右键或 `Esc` 放弃。也可以在珠宝匠处**取下**已镶嵌的宝石（单颗取下或「全部取下」）。
* **档位方向与流放之路一致：T1 最强、T8 最弱**（档位由物品等级决定，8 档分界为 ilvl 1/8/17/27/39/52/66/80）。
  配色：`T1 红 · T2 粉 · T3-T4 青 · T5-T6 绿 · T7-T8 灰`。
  同一档位内数值还会随物品等级向下一档插值（最多 78%），所以「同档不同级」的装备数值仍有明显差距。
* **基础数值区间**：武器 / 护甲会显示该基底在当前物品等级可能出现的数值范围（提示框里带 `范围` 前缀），而不是单独一个「上限」。
  * 单值基底（护甲）显示为 `下限 - 上限`，例如 `278 - 456`。
  * 本身就有浮动值的基底（武器伤害）直接显示成两段区间 `最低段 - 最高段`，例如 `7-9 - 10-12`（低段与高段保证不重叠）。
* **背包标识**：装上后评分会提升的装备，右上角有 **绿色 ▲**；因等级或属性不足穿不上的装备显示 **红色边框**（提示框里也会标红「需求（不满足）」）。
* **整理规则**：`稀有度优先 → 同稀有度内可提升的排前面 → 物品等级`。可提升标识只在自己所属稀有度内提前，不会越过更高稀有度的装备。
* **孔位上限按部位区分**：主手 / 副手 / 头盔 / 靴子 / 手套 / 腰带 **2 孔**，胸甲 **3 孔**，戒指 **1 孔**，项链 **2 孔**，**双手武器 4 孔**（= 主手 2 + 副手 2）。低等级装备还开不满孔，随物品等级逐步放开（每 20 物品等级多开 1 孔）。镶嵌 6 种宝石 × 5 个品质（红/绿/蓝宝石、紫水晶、黄玉、钻石）。
* **双手武器按「两手预算」给数值**：一次占掉主手 + 副手，所以
  * **基底数值 ≈ 同档单手的 2 倍**（DPS 全程稳定在 2 倍左右），
  * **词缀数值 = 单手的 2 倍**（提示框里的档位区间也按 2 倍显示，点金石同样按 2 倍区间推进），
  * **孔位上限 = 主手上限 + 副手上限**（2 + 2 = 4）。
  作为代价，装上双手武器会**顶掉副手**（反向亦然），评分对比会把被顶掉的那件算进损失，不会出现「换成副手反而显示评分提升」的假提示。
* **掉落品质随进度递进**（层数 + 难度共同决定）：
  * **1-10 层**：白装为主，蓝装少量，黄装罕见，暗金是惊喜；
  * **11-25 层**：蓝装为主，白装明显变少，词缀不满的黄装开始出现；
  * **26-40 层**：蓝黄并重，满词缀黄装出现，暗金小概率；
  * **41-55 层**：黄装为主，白装基本绝迹，暗金稳定出现；
  * **56 层以上**：多词缀黄装与暗金为主。
  难度每高一档会把阶段往前推一档并放大高稀有度权重；魔法装备掉落（MF）在其上再乘一次。高阶段的黄装不仅更常见，词缀条数也更容易掷满。
* **宝石可堆叠**，每个品质有独立图标（`◇ 碎裂 → ◈ 裂开 → ◆ 完整 → ✦ 无瑕 → ★ 完美`），地面上的掉落物也会随品质变大、增加切面。
* **珠宝匠**（城镇 NPC）提供 6×5 的合成面板：每行一种宝石、5 个格子对应 5 个品质，格子直接显示持有数量与镶嵌效果，带 `合成 →` 标记的点击即可合成，另有「一键合成全部」。
* 掉落表受 **魔法装备掉落（MF）**、难度倍率、城镇工坊等级影响；精英怪、宝箱、BOSS 有独立掉落表。
* 物品提示框会显示完整属性、孔位、宝石、暗金/传奇特效、需求，并与已装备物品做 **评分对比（▲/▼）**。
* **提示框直接给出「装备评分 / 金币价值 / 残晶价值」**：名称行右侧是本件装备的评分（和对比结论里的评分同一套权重），底部一行是出售价格（金币）与分解产出（残晶，**只算基础值，不含铁匠铺升级的额外残晶**）。左右对比时两个窗口各自显示，一眼看出谁更值钱。
* **拾取提示带类别标签**：装备按稀有度显示（`拾取 [稀有] 炽炎之握`），宝石显示 `拾取 [宝石] 碎裂的红宝石`，做装通货显示 `拾取 [通货] 裂解石`。
* **武器比「秒伤」、护甲比「坚韧」**：
  * **秒伤**：提示框列出这把武器自己的每秒伤害（`(物理均值 × 增伤 + 附加元素 × 0.9) × 攻速（含武器自身攻速词缀）`），对比时左右两窗各带 `▲ / ▼` 差值，空槽位不显示差值。
  * **坚韧**：满血时能承受的「减伤前」伤害，逐系计算 `生命 ÷ (1 − 减伤) ÷ (1 − 闪避) ÷ (1 − 受到伤害降低)`（物理用护甲减伤，火 / 冰 / 电 / 毒用对应抗性），**总坚韧 = 五类伤害的平均值**。角色面板只显示总坚韧，鼠标悬停才展开五系分项与计算输入（生命上限 / 护甲 / 闪避 / 受到伤害降低）。
* **戒指会同时显示两个戒指位的评分变化**（戒指 I / 戒指 II 各自的 `当前 → 换上后` 与 ▲/▼），右键可指定装备到哪一个槽位。戒指提示框的部位一栏也正确显示「戒指 · 精制」（以前会退化成「装备」）。

| `dropBase` | 普通怪掉装备的基础概率 |

做装与经济相关数值集中在 `js/data.js` 的 `D.ORBS`（通货石掉落权重/价格）、`D.BUILDINGS`（建筑加成与升级花费）、`D.respecCost`（洗点费用）与 `js/loot.js` 的 `L.salvageYield`（分解产出）、`L.affixRange`（词缀档位与范围）、`L.socketCap/L.socketMax`（孔位上限）。

`tools/balance.js` 的判定标准（当前三职业全部通过）：小怪击杀 0.1–4s、精英 0.3–16s、BOSS 5–95s、可承受小怪攻击 3–45 次、相邻等级伤害跳变 < 2.6 倍（保证曲线平滑、不出现跨档暴走）。

### 版本与变更记录

当前版本 **v0.0.1**（首个版本）。项目**不使用 git**，版本靠两个文件人工同步：

* `js/core.js` 的 `G.VERSION`（当前 `0.0.1`）
* `CHANGELOG.md` 顶部最新一条的标题（当前 `## [0.0.1]`）

`tools/smoke.js` 第 18 节会校验这两处一致，写歪了测试就会红。版本号遵循语义化版本：新系统走次版本 `0.x.0`，修 bug / 调数值走修订号 `0.0.x`。

玩家能看到版本号的地方：**起始界面**、**暂停界面右下角**、以及崩溃时的**错误覆盖层**（报问题时可以直接报版本）。

改完一次功能后的流程：

1. 在 `CHANGELOG.md` 顶部加一节，写清"新增 / 改动 / 修复"（格式照抄现有条目）；
2. 把 `js/core.js` 的 `G.VERSION` 改成同一个号；
3. `node tools/smoke.js 3000` 跑一遍确认没坏；
4. 想存档旧版本就整个目录复制一份（例如 `loot-arpg-v0.0.1\`），不需要额外的工具。

## 设计说明

* **全程无外部资源**：所有美术都是 Canvas 程序化绘制（形状 + 渐变 + 粒子），音效是 WebAudio 实时合成，因此整个游戏就是几个文本文件。
* **确定性随机**：地牢/掉落使用 mulberry32 可复现随机数（每层用层数派生种子），特效抖动才用非确定随机。掉落生成的随机序列刻意保持与旧版一致，做装另走独立路径，避免影响调好的数值曲线。
* **左键职责分离**：两种操作模式各自定义左键含义 —— 鼠标模式左键只移动，WASD 模式左键只攻击；按住攻击时不会顺带移动，反之亦然。远程职业在鼠标模式下会自动保持距离。
* **可重绑定输入层**：`G.Settings` 把「动作」映射到「按键」，键盘与鼠标键统一走 `pressed/down` 查询，两套模式各存一份绑定并持久化。
* **性能**：视野裁剪 + 实体按 y 排序 + 粒子上限 900 + 光照用半分辨率离屏画布 + HUD 降频刷新；同屏 150 怪物无压力。
* **可测试性**：`__HEADLESS__` 标记下不自动启动主循环，`tools/smoke-shim.js` 提供 DOM/Canvas 垫片，让 Node 能跑完整游戏更新逻辑（含城镇与地牢两种场景的渲染帧）。垫片里的 canvas 会像浏览器一样拒绝 `NaN` / `Infinity` 参数，因此渲染层的数值错误会在测试里直接暴露（`main.js` 还留了一个 `G.frameOnce` 钩子，可在无头环境按真实帧推进）。

## 已知限制

* 单位只有圆形碰撞 + 沿墙滑动，没有寻路网格：怪物在被墙完全隔开时会绕墙（有侧移回退），但不会计算最短路。
* 存档不含地牢布局（换层重新生成）；回城时地上未拾取的物品会消失。
* 城镇是固定的手工布局，不会随机生成，也没有昼夜或 NPC 作息。
* 没有联机、没有手柄支持；移动端可看但未针对触摸操作优化。
